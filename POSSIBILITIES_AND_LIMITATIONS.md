# Возможности и ограничения

**Решение:** Архитектор BPMN-диаграмм — ПАО «Интер РАО»  
**Хакатон:** ИИ-ассистенты для энергетики

---

## Возможности

### Генерация валидного BPMN 2.0.2 из текста за секунды
Превращает текстовый регламент на русском языке в валидную BPMN-диаграмму. Генерирует XML, соответствующий официальной XSD-схеме BPMN 2.0.2 (OMG). Файл открывается и редактируется в [demo.bpmn.io](https://demo.bpmn.io) без ошибок и предупреждений.

**Результат:** 3-5 секунд генерации, 100% XSD compliance, zero manual layout.

---

### Участники, последовательность, ветвления
Автоматически определяет роли из текста и создаёт дорожки (swimlanes). Строит последовательность действий по шагам регламента. Создаёт шлюзы XOR (exclusive), AND (parallel), OR (inclusive) с условиями. Поддерживает возвратные стрелки на доработку (rework loops).

**Результат:** Ортогональные стрелки (90°), без наложений блоков и подписей — читаемая диаграмма, а не «карта метро».

---

### Автоматический аудит бизнес-архитектуры
Считает bus-factor (доля задач у одной роли, порог 45%). Находит критический путь SLA алгоритмом Беллмана-Форда. Выявляет циклы возврата с временем каждого цикла. Извлекает ИТ-системы и документы из текста регламента. Генерирует рекомендации по оптимизации.

**Результат:** Аудит до внедрения (shift-left) — предиктивное выявление рисков вместо expensive fixes.

---

### Работа в трёх режимах: облако, офлайн, без LLM
Облачный LLM (Groq, OpenRouter) для быстрого prototyping. Ollama (офлайн) для локальных моделей в закрытом контуре. Встроенный эмулятор работает без нейросети. Graceful degradation: всегда возвращает результат.

**Результат:** Гибкость для любого контура — от демо до защищённой среды Интер РАО.

---

### AI-ассистент для интерактивной оптимизации
Анализирует узкие места по цифрам аудита. Правит регламент на естественном языке и перестраивает диаграмму. Генерирует должностные инструкции из BPMN.

**Результат:** Эксперименты с процессами без ручного моделирования — iteration cycle в минутах вместо дней.

---

### Загрузка и выгрузка документов
Загружает регламенты из DOCX, PDF, TXT. Очищает текст от колонтитулов, переносов слов, многоуровневой нумерации. Выгружает BPMN XML, SVG, Паспорт процесса (Markdown с RACI, регламентом, ИТ-ландшафтом).

**Результат:** Работа с реальными документами — без ручной перепечатки.

---

### MCP-интеграция в корпоративные агенты
MCP-сервер (JSON-RPC 2.0, stdio). Инструменты: generate_bpmn, analyze_bottlenecks, get_it_landscape. Интеграция в Cursor, Claude Desktop, внутренние агенты.

**Результат:** BPMN-генерация как building block для сложных agents — без HTTP-обвязки.

---

## Ограничения

### Фокус на основной сценарий: один процесс с дорожками
Решение оптимизировано для моделирования бизнес-процессов внутри одной организации. Поддерживается один процесс с дорожками (swimlanes). Внешние стороны моделируются отдельными дорожками внутри пула.

**Контекст:** Для операционных процессов Интер РАО (ремонт, закупки, ТО) этого достаточно. Расширение на несколько пулов не увеличивает ценность для основного сценария.

---

### SLA в аудите, а не в нотации событий
Сроки учитываются в аудите SLA (критический путь в часах), а не через события-таймеры BPMN. Не поддерживаются timer events, boundary events, message events.

**Контекст:** Для бизнес-архитектуры Интер РАО достаточно числовой оценки SLA. Исполнение процессов — задача BPMS (Camunda, Bizagi), не этого инструмента.

---

### ИТ-системы и документы в аналитике, не на диаграмме
ИТ-системы и документы выводятся в блоке «ИТ-ландшафт и документооборот» с привязкой к шагам и ролям. Не добавляются как data objects на диаграмму.

**Контекст:** Чтобы не загромождать диаграмму. В аналитике они доступны и структурированы — это более практично для бизнес-архитектора.

---

### Офлайн-режим: локальные модели медленнее
Локальная модель 7B на ноутбуке отвечает 2-4 минуты. Качество графа ниже, чем у облачных моделей.

**Контекст:** Офлайн-режим для закрытого контура — скорость не критична, важна доступность. Для продакшена рекомендуется серверное оборудование с GPU.

---

### Эмулятор: fail-safe режим
Эмулятор рассчитан на нумерованные шаги («1.», «2.», …). Сплошной текст и английский разбирает хуже.

**Контекст:** Эмулятор — резервный режим, когда LLM недоступен. Регламенты Интер РАО обычно нумерованы. Основной режим — облачный LLM.

---

### Совместимость с bpmn.io
bpmn.io игнорирует часть стилей подписей из XML. XML валиден по XSD BPMN 2.0.2. Enterprise-инструменты (Camunda, Signavio) поддерживают все стили.

**Контекст:** bpmn.io — один из инструментов для просмотра. Для продакшена Используются enterprise-инструменты с полной поддержкой стилей.
